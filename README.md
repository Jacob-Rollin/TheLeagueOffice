# The League Draft Tool

A web app fantasy football draft tool that uses free API’s for player rankings, ADP, player stats, projections, etc. Use half-PPR as the default scoring system. Have custom settings including number of teams, number of rounds in the draft, and positions.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://welcometotheleague.lovable.app
